# 🌟 SimpleWatermark - FiveM Script [ESX / QB Core / Standalone]

---
## 🎯 Features
- Displays a custom watermark in the top-right corner.
- Uses local (offline) font, no need for Google Fonts.
- Easy to customize (color, position, size, font).
  
---
## 🧩 Instalasi
1. Download or clone this repository into your server’s `resources` folder:
   ```cfg
   git clone https://github.com/Comethruuu/SimpleWatermark.git
   ```
2. Tambahkan ke `server.cfg`:
   ```cfg
   ensure SimpleWatermark
   ```

---
## ⚙️ Configuration
1. Change the watermark text in `index.html`
   ```bash
   <div id="watermark">#CLOUDSERVER/div>
   ```
2. Edit styles in `style.css`
